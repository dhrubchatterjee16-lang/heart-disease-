This project utilizes machine learning to predict the presence of heart disease in patients based on clinical parameters. By analyzing physiological data, the model identifies high-risk individuals, potentially assisting healthcare providers in early intervention.

Project Overview
The goal of this project is to build a robust binary classifier that predicts whether a patient has heart disease (target = 1) or not (target = 0). This project involves data cleaning, exploratory data analysis (EDA), and comparing multiple classification algorithms.

Dataset Features
The dataset contains 14 key attributes frequently used in cardiac diagnosis:

Age: Age in years.

Sex: (1 = male; 0 = female).

Chest Pain Type (cp): Type of pain (0-3).

Resting BP (trestbps): Resting blood pressure in mm Hg.

Cholesterol (chol): Serum cholesterol in mg/dl.

Fasting Blood Sugar (fbs): (1 = true; 0 = false).

Restecg: Resting electrocardiographic results.

Thalach: Maximum heart rate achieved.

Tech Stack
Language: Python 3.9+

Libraries: Scikit-learn, Pandas, NumPy

Visualization: Seaborn, Matplotlib, Plotly





Exang: Exercise-induced angina (1 = yes; 0 = no).

Oldpeak: ST depression induced by exercise relative to rest.
